# ChunkSend website

Send files and whole folders directly from one device to another — no server,
no account, nothing stored anywhere in between. Open `index.html` in any
modern browser, or visit the GitHub Pages site.

## First step: your key file

ChunkSend only works between devices holding the **same key file**. On the
page, choose **Create a key file** — it is generated in your browser and
downloads straight to you; it is never sent or stored anywhere. Load that
same file on every device you want in your circle.

Different keys mean different circles: nobody else's key can open your codes
or packages, and your key can't open theirs.
